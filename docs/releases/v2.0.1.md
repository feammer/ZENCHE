# 帧澈 ZENCHE 2.0.1 发布说明

> 版本：`2.0.1 / build 44`
> 发布分支：`remove-ai-features`
> 日期：2026-11-16（Asia/Shanghai）

## 本次更新

2.0.1 清理了更新公告、Mirror酱与反馈/赞助入口，并统一了仓库链接。

### 移除

- **启动更新公告**：五端启动时的版本公告弹窗、“不再提醒”持久化与公告文案。
- **Mirror酱更新链路**：设置中的 CDK 输入、保存与打开入口，Mirror酱 CDN 请求、
  增量包判断、错误回退文案与相关 Keychain/Keystore/DPAPI 存储代码。
- **快速问题反馈与爱发电**：设置中的快速反馈卡片、爱发电赞助/兑换按钮、二维码
  弹窗与捐赠入口。
- **旧仓库链接**：应用内 GitHub Release、Issue、更新检查与项目主页链接由
  `Tauber01/ZENCHE` 改为 `feammer/ZENCHE`。

### 保留

- 自托管更新接口与 GitHub Releases 回退；更新状态、当前版本与检查按钮。
- 相机连接、监看、拍摄、外录、文件库、专业显影、诊断日志与三语界面。
- 诊断日志的“上传脱敏日志”仍打开当前仓库的 Issue 页面。

## 升级指引

1. 覆盖安装即可；本地文件库、编辑参数与相机配置不受影响。
2. 不再支持 Mirror酱 CDK 更新，请使用 GitHub Releases 或自托管更新源。
3. 需要旧版公告/Mirror酱能力时可继续使用 2.0.0。
