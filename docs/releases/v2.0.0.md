# 帧澈 ZENCHE 2.0.0 发布说明

> 版本：`2.0.0 / build 43`
> 发布分支：`remove-ai-features`
> 日期：2026-11-08（Asia/Shanghai）

## 本次更新

2.0.0 是一次**功能移除型**大版本：应用不再包含账号系统与云端 AI，
启动后直接进入本地工作台。

### 移除

- **账号系统**：邮箱注册、登录墙、会话校验、账号设置与退出登录。
- **云端 AI**：AI 修图、AI 生图、提示词与预设、宽高比/分辨率选择、
  服务端次数统计与错误详情。
- **激活体系**：激活码输入与本地验签、兑换入口、设备 ID、设备码恢复/换绑、
  剩余次数显示与本地持久化。
- **服务端与管理台**：`ai-server/`（AI 代理、账号 API、换绑签发端、管理台）。
- **官网源码与部署**：`website/`、`website-vue/`、Pages 工作流。
- **AI 专用网络配置**：历史明文代理 `101.34.255.115`、`/v1/ai`、`/v1/auth`
  请求与相关测试。

### 保留

- USB/PTP 与 Wi‑Fi PTP/IP 相机连接、心跳与自动重连
- 实时监看、RGB/音频波形、LUT、峰值、假色、斑马纹
- 拍摄、间隔/包围、焦点合成、延时合成、Live Photo、外录
- 文件库、RAW+JPEG、备份、SHA-256、XMP、系统相册导入/导出
- 专业显影（非破坏编辑）、Nikon 云创预设
- 设备端画面分析与本地批量调整（不联网、不消耗次数）
- 自动更新检查（不依赖账号）、诊断日志、三语界面

## 验证

- `npm test`：295 通过、0 失败、16 跳过（宿主缺少对应工具链的用例跳过）。
- Windows：`dotnet build native/windows/NikonLink.Windows.csproj -c Release` 0 错误。
- 已删除不再适用的 AI/账号契约测试；非 AI 覆盖的重建计划见 `docs/TODO.md`。
- 真机相机、安装/升级、系统相册与长时间稳定性仍需对应设备验收。

## 已知限制

- HarmonyOS 与 macOS 仍保留部分已下线的账号/AI 辅助代码；macOS 的功能入口
  尚未移除，详见 `docs/TODO.md`。
- 本版本未产出 HarmonyOS HAP 与 macOS DMG；CI 缺少对应的鸿蒙工具链与
  Nikon/Sony 专有 SDK。
- `release.yml` 仍按六包白名单校验，本版本不使用该工作流发布。
- 应用内 2.0.0 更新公告文案尚未同步（见 TODO）。

## 升级指引

1. 旧版本的用户账号与激活信息不再使用，升级不会影响本地文件库与编辑参数。
2. 覆盖安装前建议保留相机存储卡与本地文件库备份。
3. 如只需旧版 AI/账号能力，请继续使用 1.5.15。
